Satchel Tunables

How a dev-tuned balance value flows. Code declares a Tunable with a range and default. The server merges the shipped seed CSV with the live config CSV at start and writes the live CSV at stop. FrontierMode's Gradle run tasks copy the live CSV back over the seed. A Tunable reads its value once, when it's constructed.
