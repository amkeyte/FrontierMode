Satchel Networking

How bundle state reaches the client. One-way, server to client. A server bundle resends its whole snapshot every 100 ticks on the execution pulse, whether or not it's dirty, plus whenever forceSync is called. The client keeps only the latest parcel per bundle and applies it on its own pulse. The same channel carries the world-identity token that makes the client foundation ready at all.
