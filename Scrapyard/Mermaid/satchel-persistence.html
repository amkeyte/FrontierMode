Satchel Persistence

How a bundle's fixtures reach disk and come back. Server only. There is one vanilla SavedData per bundle key, stored in the scope's reference level. Satchel writes the snapshot into it and marks it dirty; vanilla's own world save writes the file, unless a caller forces an immediate save.
