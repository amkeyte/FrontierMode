# Nethack Ideas (Parked)

**Status: parked.** These are Nethack-derived ideas that are not part of the core loop's current
design scope (see [Frontier Mode Overview](overview.md)), kept on record deliberately so the core
systems — [Progression & Frontier Mechanics](progression.md), [Boss Discovery](boss-discovery.md),
[Guardian Mobs](guardian-mobs.md) — can be built with these in mind rather than having them
band-aided in after the fact once the core loop is working.

## Secret shops

The one specific idea named so far: Nethack-style secret shops. Not yet designed — no mechanic,
placement, or economy attached. Worth developing once the core loop's item/reward economy (see
[Boss Discovery](boss-discovery.md#the-discovery-gradient) and [Progression &
Frontier Mechanics](progression.md#resource-and-reward-density)) has enough shape that a shop
system has something real to plug into, rather than being designed in a vacuum.

## Open for more

This page exists to keep growing. Additional Nethack-inspired ideas — item identification,
class/role identity, deeper risk/reward item interaction — are all in scope for this mode
eventually, per the [Game Designer role's purpose](../../../roles/game-designer.md), but are
intentionally not detailed here until there's a core loop working to build them on top of.
